# OptiGest - Backend

Repositorio academico del backend de OptiGest, presentado como Trabajo Final
Integrador de la Tecnicatura Universitaria en Programacion.

## Tecnologias

- C# y .NET 8
- ASP.NET Core Web API
- Entity Framework Core y SQL Server
- Autenticacion JWT y autorizacion por roles

## Funcionalidades

- Gestion de usuarios, clientes, productos y vehiculos.
- Ventas, pagos, cuenta corriente y financiaciones.
- Control de stock y configuracion comercial.
- Dashboard y consultas de negocio.

## Configuracion local

Esta copia no contiene credenciales ni conexiones reales. Configura una cadena
de conexion y la clave JWT mediante User Secrets o variables de entorno locales;
nunca las agregues al repositorio.

## Procedencia academica

El contenido fue exportado sin historial Git desde el commit estable
`9d852ed11314041a4f4fdd182e85acebdc55d2bf`. Se elimino el identificador local
de User Secrets para evitar vinculos con configuraciones privadas. Los fixtures
de prueba son sinteticos y se ejecutan solamente con infraestructura aislada.
